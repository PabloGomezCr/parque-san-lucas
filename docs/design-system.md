# Extracción histórica del sistema visual

> Los colores extraídos aquí documentan Stitch original. La instrucción posterior del usuario los reemplaza: ver [sistema vigente de color y branding](color-system.md). La estructura y tipografía siguen siendo referencia.

Referencias: A01, T01, T03, D01, DS01 y láminas 18–20, 31. Las pantallas operativas claras usan azul pizarra, no naranja como CTA.

- Inter 400/500/600/700; 14 px cuerpo, 12 px labels, 32/40 px encabezados, 30/36 px métricas.
- Fondo #f7f9ff; texto #141c24; texto secundario #44474e.
- Acción #5a7092; acción fuerte #425878; selección #edf4ff.
- Sidebar 288 px; topbar 64 px; padding principal 32 px; gaps 16/24 px.
- Superficies blancas translúcidas 70–80%, blur 12–24 px.
- Controles 8 px de radio; cards 12–16 px; pills redondas.
- Dark: tokens de lámina 19, misma estructura.
- Branding: recuperar imágenes originales enlazadas en HTML; no redibujar el pelícano.
